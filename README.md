
# Angry Goose Game

A simple interactive game developed in Java using Processing as part of my Computer Science studies.

## About the Project

The objective is to control a goose and hit a target. The game demonstrates fundamental programming concepts, including object-oriented programming, keyboard input, movement, and collision detection.

## Technologies Used

- Java
- Processing

## How to Run

1. Download and install Processing.
2. Open `AngryGooseGame.pde` in Processing.
3. Select Java mode.
4. Click Run to launch the game.

## What I Learned

- Creating classes and objects
- Handling keyboard input
- Implementing movement and collision detection
- Organising code into methods
